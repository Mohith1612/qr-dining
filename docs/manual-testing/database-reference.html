Lifecycle Flows

Session
active → payment_pending → (settled) closed
Idle with no presence: active → awaiting_reactivation (≈60s grace) → abandoned (≈5m window). Reconnect within window re-activates via snapshot. A session with a non-terminal payment is never abandoned. Terminal states readable 60 min.
Order
pending → confirmed → preparing → ready → served  (or → cancelled)
Kitchen advances up to ready; only a waiter marks served (server-enforced). Items snapshot price.
Payment
pending → requested → {provider_pending → (webhook) | requires_staff_confirmation → (staff settle)} → completed
Initiation freezes the cart + captures bill_snapshots. Workers never fabricate settlement (alert-only escalation). Completion typically closes the session.
Subscription
trial → active → {suspended ↔ active} → cancelled / expired (past_due)
Org-level state machine; transitions recorded. Resolve-only today (not enforced on operational paths).
Theme
tenant_themes(preset+tokens) → guest UI adopts via [data-theme]
Structured tokens are authoritative; legacy settings_json.theme is bridged, not dropped.
Collateral
branch_collateral(config) + tenant_theme + branch metadata → rendered print formats
Collateral consumes the theme (no second branding system); platform & staff write one shared row.
Support
search → inspect (sanitized) → audit (internal + tenant-visible critical)
Read-only; never exposes session_token/device_fingerprint; every deep read is audited.
